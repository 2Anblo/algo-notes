# 动态规划模板总结

> 基于「代码随想录」动态规划 42 题提炼，一文搞懂 DP 核心套路。

## 一、DP 核心方法论 —— 动规五部曲

做任何 DP 题，先回答这五个问题：

| 步骤 | 问题 | 说明 |
|:---:|------|------|
| 1 | **dp 数组的含义是什么？** | 状态定义，决定了整道题的方向 |
| 2 | **递推公式是什么？** | 状态之间如何转移 |
| 3 | **dp 数组如何初始化？** | 边界条件，递推的起点 |
| 4 | **遍历顺序是什么？** | 从递推公式推出：谁先算、谁后算 |
| 5 | **举例推导 dp 数组** | 手动跑一遍验证，debug 利器 |

> 💡 **核心心法**：定义好 dp → 推公式 → 确定遍历顺序，三步走完代码就出来了。

## 二、基础 DP（斐波那契 / 爬楼梯 / 最小花费）

### 核心思想

最简单的线性递推，当前状态只依赖前 1~2 个状态。

### 通用模板

```java
// dp[i]：到达第 i 步的最优解
int[] dp = new int[n + 1];
dp[0] = ...;  // 初始化
dp[1] = ...;  // 初始化

for (int i = 2; i <= n; i++) {
    dp[i] = 由 dp[i-1], dp[i-2] 转移而来;
}
return dp[n];
```

### 各题要点

| 题目 | dp 含义 | 递推公式 | 特点 |
|------|---------|---------|------|
| 509.斐波那契数 | dp[i] = 第 i 个斐波那契数 | `dp[i] = dp[i-1] + dp[i-2]` | 最朴素的线性递推 |
| 70.爬楼梯 | dp[i] = 爬到第 i 阶的方法数 | `dp[i] = dp[i-1] + dp[i-2]` | 与斐波那契同构 |
| 746.最小花费爬楼梯 | dp[i] = 到达第 i 阶的累计最小花费 | `dp[i] = min(dp[i-1]+cost[i-1], dp[i-2]+cost[i-2])` | 取 min，注意可从 0 或 1 出发 |

### 空间优化

只需两个变量滚动即可，空间 O(n) → O(1)：

```java
int a = 0, b = 1;
for (int i = 2; i <= n; i++) {
    int c = a + b;  // 或其他转移
    a = b;
    b = c;
}
return b;
```

## 三、路径 DP（不同路径 / 障碍物）

### 核心思想

二维网格上的递推，当前格子只能从「上方」或「左方」到达。

### 通用模板

```java
// dp[i][j]：从起点到 (i,j) 的路径数
int[][] dp = new int[m][n];

// 初始化第一行、第一列为 1
for (int i = 0; i < m; i++) dp[i][0] = 1;
for (int j = 0; j < n; j++) dp[0][j] = 1;

for (int i = 1; i < m; i++) {
    for (int j = 1; j < n; j++) {
        dp[i][j] = dp[i-1][j] + dp[i][j-1];  // 上 + 左
    }
}
return dp[m-1][n-1];
```

### 有障碍物的处理

```java
// 初始化时遇到障碍物就 break（后面的都到不了）
for (int i = 0; i < m; i++) {
    if (obstacleGrid[i][0] == 1) break;
    dp[i][0] = 1;
}
// 递推时障碍物位置 dp[i][j] = 0
```

| 题目 | 关键点 |
|------|--------|
| 62.不同路径 | 基础模板 |
| 63.不同路径II | 障碍物处 dp=0，初始化遇障碍 break |

## 四、0-1 背包模板

### 核心思想

每种物品**最多选一次**，求容量限制下的最优解。

### 二维 → 一维滚动数组优化

**二维写法**（理解用）：

```java
// dp[i][j]：从前 i 个物品中选，容量为 j 时的最大价值
for (int i = 0; i < m; i++) {
    for (int j = 0; j <= n; j++) {
        if (j < weight[i]) {
            dp[i][j] = dp[i-1][j];           // 放不下
        } else {
            dp[i][j] = Math.max(dp[i-1][j],  // 不放
                                dp[i-1][j-weight[i]] + value[i]);  // 放
        }
    }
}
```

**一维写法**（实战用，**内层倒序遍历**）：

```java
// dp[j]：容量为 j 时的最大价值
int[] dp = new int[bagSize + 1];

for (int i = 0; i < m; i++) {              // 外层遍历物品
    for (int j = bagSize; j >= weight[i]; j--) {  // ⚠️ 内层倒序！
        dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
    }
}
```

### ⚠️ 为什么必须倒序？

正序遍历时，`dp[j - weight[i]]` 可能在当前轮已经被更新过（包含了当前物品），导致同一物品被重复选取。**倒序保证每个物品只用一次**。

### 适用题目

| 题目 | 转化思路 | 递推公式变体 |
|------|---------|-------------|
| 46.携带研究材料 | 标准 0-1 背包 | `max(不放, 放)` |
| 416.分割等和子集 | 背包容量 = sum/2，判断能否恰好装满 | `dp[target] == target` |
| 1049.最后一块石头的重量II | 分成两堆，差值最小 | 等价 416，答案 `sum - 2*dp[target]` |
| 494.目标和 | 凑出正数和 left = (target+sum)/2，求方案数 | `dp[j] += dp[j-num]`（组合数） |
| 474.一和零 | 两种容量（0 的个数 + 1 的个数） | 二维 dp，双层倒序 |

### 494.目标和 的关键推导

```
设正数和 left，负数和 right
left - right = target
left + right = sum
→ left = (target + sum) / 2
```

这就变成了：**从 nums 中选若干数，使其和恰好等于 left 的方案数**。

### 474.一和零 —— 双维度 0-1 背包

```java
int[][] dp = new int[m + 1][n + 1];  // 两种容量
for (String s : strs) {
    int zeros = 统计0的个数, ones = 统计1的个数;
    for (int i = m; i >= zeros; i--) {       // 双层倒序
        for (int j = n; j >= ones; j--) {
            dp[i][j] = Math.max(dp[i][j], dp[i-zeros][j-ones] + 1);
        }
    }
}
```

## 五、完全背包模板

### 核心思想

每种物品**可以选无限次**，与 0-1 背包的唯一区别：**内层正序遍历**。

### 通用模板

```java
int[] dp = new int[bagSize + 1];

for (int i = 0; i < m; i++) {                  // 外层物品
    for (int j = weight[i]; j <= bagSize; j++) { // ⚠️ 内层正序！
        dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
    }
}
```

### ⚠️ 组合 vs 排列 —— 遍历顺序决定结果

这是完全背包中**最容易踩坑**的地方：

| 问题类型 | 遍历顺序 | 含义 |
|---------|---------|------|
| **组合数**（顺序无关） | 外层物品，内层容量 | 先固定物品，保证不重复计数 |
| **排列数**（顺序有关） | 外层容量，内层物品 | 对每个容量尝试所有物品，顺序不同算不同方案 |

```
组合：{1,2} 和 {2,1} 算一种
排列：{1,2} 和 {2,1} 算两种
```

### 组合数模板（518.零钱兑换II）

```java
dp[0] = 1;
for (int coin : coins) {              // 外层物品
    for (int j = coin; j <= amount; j++) {  // 内层容量
        dp[j] += dp[j - coin];        // 方案数累加
    }
}
```

### 排列数模板（377.组合总和IV）

```java
dp[0] = 1;
for (int i = 1; i <= target; i++) {   // 外层容量
    for (int num : nums) {             // 内层物品
        if (i >= num) dp[i] += dp[i - num];
    }
}
```

### 适用题目

| 题目 | 类型 | 关键点 |
|------|------|--------|
| 52.携带研究材料 | 完全背包求最大价值 | 内层正序 |
| 518.零钱兑换II | 组合数 | 外层物品，内层容量 |
| 377.组合总和IV | 排列数 | 外层容量，内层物品 |
| 70.爬楼梯(完全背包) | 排列数 | 外层台阶，内层步长 |
| 322.零钱兑换 | 求最少硬币数 | `min(不选, 选)` + 初始化 INF |
| 279.完全平方数 | 求最少数量 | 物品为 1²,2²,3²... |
| 139.单词拆分 | 判断能否拼出 | boolean dp，外层容量内层物品 |
| 56.携带矿石资源(混合背包) | 多重背包 | 每种物品有数量上限，拆成多次 0-1 背包 |

### 322.零钱兑换 —— 求最少的模板

```java
Arrays.fill(dp, amount + 1);  // 初始化为"不可能"的大值
dp[0] = 0;
for (int coin : coins) {
    for (int j = coin; j <= amount; j++) {
        dp[j] = Math.min(dp[j], dp[j - coin] + 1);
    }
}
return dp[amount] == amount + 1 ? -1 : dp[amount];
```

### 56.混合背包 —— 有数量限制的完全背包

```java
for (int i = 0; i < N; i++) {
    // 将"最多 k[i] 个"拆成 k[i] 次 01 背包
    for (int k1 = 0; k1 < k[i]; k1++) {
        for (int j = C; j >= w[i]; j--) {  // 倒序！01背包
            dp[j] = Math.max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
}
```

## 六、打家劫舍系列（线性 → 环形 → 树形）

### 线性打家劫舍（198）

```java
// dp[i]：偷到第 i 间房时的最大金额
dp[0] = nums[0];
dp[1] = Math.max(nums[0], nums[1]);

for (int i = 2; i < len; i++) {
    dp[i] = Math.max(dp[i-1], dp[i-2] + nums[i]);
    //        不偷当前      偷当前（跳过前一间）
}
```

### 环形打家劫舍（213）

首尾相连 → **首尾不能同时偷** → 拆成两个线性问题：

```java
// 情况1：偷 [0, len-2]，不偷最后一间
// 情况2：偷 [1, len-1]，不偷第一间
return Math.max(robRange(nums, 0, len-1), robRange(nums, 1, len));
```

### 树形打家劫舍（337）

在树上做 DP，每个节点返回两个值：

```java
// result[0]：不偷当前节点的最大金额
// result[1]：偷当前节点的最大金额
public int[] robTree(TreeNode node) {
    if (node == null) return new int[]{0, 0};

    int[] left = robTree(node.left);
    int[] right = robTree(node.right);

    // 不偷：左右孩子各取 max(偷,不偷)
    int notRob = Math.max(left[0], left[1]) + Math.max(right[0], right[1]);

    // 偷：左右孩子都不能偷
    int rob = node.val + left[0] + right[0];

    return new int[]{notRob, rob};
}
```

### 演进路线

```
线性 (198) → 环形拆分 (213) → 树形递归 (337)
```

## 七、买卖股票系列（状态机 DP）

### 统一框架

所有股票题都可以用**状态机**统一：`dp[i][状态]` 表示第 i 天结束时的最大利润。

**核心状态**：
- `0`：持有股票
- `1`：不持有股票

### 只买卖一次（121）

```java
dp[i][0] = max(dp[i-1][0], -prices[i])                // 只能买一次，之前利润为0
dp[i][1] = max(dp[i-1][1], dp[i-1][0] + prices[i])
```

### 可多次买卖（122）

```java
dp[i][0] = max(dp[i-1][0], dp[i-1][1] - prices[i])    // 买入时用上一轮卖出的利润
dp[i][1] = max(dp[i-1][1], dp[i-1][0] + prices[i])
```

### 最多 K 次交易（123 / 188）

扩展状态维度：`dp[i][2k+1]`，奇数 = 买入，偶数 = 卖出。

```java
// 状态编号：0=初始, 1=第一次买入, 2=第一次卖出, 3=第二次买入, 4=第二次卖出, ...
for (int i = 1; i < prices.length; i++) {
    for (int j = 1; j <= k; j++) {
        // 第 j 次买入
        dp[i][2*j-1] = Math.max(dp[i-1][2*j-1], dp[i][2*j-2] - prices[i]);
        // 第 j 次卖出
        dp[i][2*j]   = Math.max(dp[i-1][2*j],   dp[i][2*j-1] + prices[i]);
    }
}
```

初始化：所有买入状态 = `-prices[0]`，所有卖出状态 = `0`。

### 含冷冻期（309）

增加状态：4 个状态

| 状态 | 含义 | 转移来源 |
|------|------|---------|
| 0 | 持有股票 | 昨天持有 / 今天买入（从状态1或3） |
| 1 | 不持有，非冷冻 | 昨天不持有 / 昨天冷冻结束 |
| 2 | 今天卖出 | 昨天持有 + 卖出 |
| 3 | 冷冻期 | 昨天刚卖出 |

```java
dp[i][0] = max(dp[i-1][0], dp[i-1][1] - prices[i], dp[i-1][3] - prices[i]);
dp[i][1] = max(dp[i-1][1], dp[i-1][3]);
dp[i][2] = dp[i-1][0] + prices[i];
dp[i][3] = dp[i-1][2];
// 答案：max(状态1, 状态2, 状态3)
```

### 含手续费（714）

在卖出时扣费即可，其余同 122：

```java
dp[i][0] = max(dp[i-1][0], dp[i-1][1] - prices[i]);
dp[i][1] = max(dp[i-1][1], dp[i-1][0] + prices[i] - fee);  // 卖出扣 fee
```

### 一图总结

```
121(1次) ──→ 122(无限次) ──→ 123(2次) ──→ 188(K次)
                │                              │
                +-- 309(+冷冻期)               +-- 714(+手续费)
```

## 八、子序列 DP（LIS / LCS / 编辑距离）

### LIS：最长递增子序列（300）

```java
// dp[i]：以 nums[i] 结尾的 LIS 长度
Arrays.fill(dp, 1);
for (int i = 1; i < n; i++) {
    for (int j = 0; j < i; j++) {
        if (nums[j] < nums[i]) {
            dp[i] = Math.max(dp[i], dp[j] + 1);
        }
    }
}
// 答案是 max(dp[])，不是 dp[n-1]
```

> 💡 复杂度 O(n²)，可用二分优化到 O(n log n)。

### 最长连续递增序列（674）

```java
if (nums[i] > nums[i-1]) dp[i] = dp[i-1] + 1;
else dp[i] = 1;
```

### 最长重复子数组（718）—— 连续版 LCS

```java
// dp[i][j]：以 nums1[i-1] 和 nums2[j-1] 结尾的最长公共子数组长度
if (nums1[i-1] == nums2[j-1]) {
    dp[i][j] = dp[i-1][j-1] + 1;
}
// 不等则为 0（必须连续）
// 答案是全局 max
```

### LCS：最长公共子序列（1143）—— 不连续版

```java
// dp[i][j]：text1 前 i 个与 text2 前 j 个的 LCS 长度
if (c1[i-1] == c2[j-1]) {
    dp[i][j] = dp[i-1][j-1] + 1;
} else {
    dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]);
}
```

### 1035.不相交的线

本质就是 LCS，代码完全一样。

### 53.最大子序和

```java
// dp[i]：以 nums[i] 结尾的连续子数组最大和
dp[i] = Math.max(dp[i-1] + nums[i], nums[i]);
// 接上去 vs 重新开始
```

### 392.判断子序列

LCS 变体，检查 `LCS长度 == s.length()` 即可。

### 115.不同的子序列

```java
// dp[i][j]：s 前 i 个字符中出现 t 前 j 个字符的方案数
if (s[i-1] == t[j-1]) {
    dp[i][j] = dp[i-1][j-1] + dp[i-1][j];  // 用 + 不用
} else {
    dp[i][j] = dp[i-1][j];                  // 只能不用 s[i]
}
// 初始化：dp[i][0] = 1（空串有一种匹配方案）
```

### 583.两个字符串的删除操作

方法一：LCS 长度，答案 = `len1 + len2 - 2 * lcs`

方法二：直接定义 dp 为删除次数：

```java
if (ch1[i-1] == ch2[j-1]) {
    dp[i][j] = dp[i-1][j-1];
} else {
    dp[i][j] = Math.min(dp[i-1][j] + 1, dp[i][j-1] + 1);
}
```

### 🏆 编辑距离（72）—— 子序列 DP 的集大成者

```java
// dp[i][j]：word1 前 i 个字符变成 word2 前 j 个字符的最少操作数

// 初始化
dp[i][0] = i;   // 全删
dp[0][j] = j;   // 全插

// 转移
if (ch1[i-1] == ch2[j-1]) {
    dp[i][j] = dp[i-1][j-1];                    // 不操作
} else {
    dp[i][j] = Math.min(
        dp[i-1][j] + 1,      // 删除 word1[i-1]
        Math.min(
            dp[i-1][j-1] + 1, // 替换
            dp[i][j-1] + 1    // 插入（等价于删除 word2[j-1]）
        )
    );
}
```

**四种操作一览**：

| 操作 | 转移 | 含义 |
|------|------|------|
| 不操作 | `dp[i-1][j-1]` | 字符相同，跳过 |
| 删除 | `dp[i-1][j] + 1` | 删掉 word1 当前字符 |
| 替换 | `dp[i-1][j-1] + 1` | 把 word1 当前字符换成 word2 的 |
| 插入 | `dp[i][j-1] + 1` | 在 word1 插入 word2 当前字符 |

> 💡 删除和插入互为逆操作：删 word1 的字符 = 插 word2 的字符。

### 子序列 DP 进化树

```
LIS(300) ──→ 连续LIS(674)
                         ↘
LCS(1143) ──→ 重复子数组(718) ──→ 不相交线(1035)
     ↓
判断子序列(392) ──→ 不同子序列(115)
     ↓
删除操作(583) ──→ 🏆编辑距离(72)
```

## 九、回文 DP

### 647.回文子串 —— 统计个数

**DP 法**：

```java
// dp[i][j]：s[i..j] 是否为回文串
// 遍历顺序：从下往上（i 递减），从左往右（j 递增）
// 因为 dp[i][j] 依赖 dp[i+1][j-1]
for (int i = len - 1; i >= 0; i--) {
    for (int j = i; j < len; j++) {
        if (ch[i] == ch[j]) {
            if (i == j)          dp[i][j] = true;      // 单字符
            else if (i == j - 1) dp[i][j] = true;      // 双字符相同
            else if (dp[i+1][j-1]) dp[i][j] = true;    // 内部是回文
        }
        if (dp[i][j]) result++;
    }
}
```

**中心扩展法**（更直觉，空间 O(1)）：

```java
for (int center = 0; center < 2 * len - 1; center++) {
    int left = center / 2;
    int right = left + center % 2;
    while (left >= 0 && right < len && s[left] == s[right]) {
        result++;
        left--; right++;
    }
}
```

### 516.最长回文子序列 —— 求长度

```java
// dp[i][j]：s[i..j] 中最长回文子序列长度
for (int i = len - 1; i >= 0; i--) {
    dp[i][i] = 1;  // 单字符
    for (int j = i + 1; j < len; j++) {
        if (ch[i] == ch[j]) {
            dp[i][j] = dp[i+1][j-1] + 2;    // 首尾加入回文
        } else {
            dp[i][j] = Math.max(dp[i+1][j], dp[i][j-1]);  // 舍一边
        }
    }
}
return dp[0][len-1];
```

### 两种回文 DP 的区别

| | 回文子串 (647) | 最长回文子序列 (516) |
|---|---|---|
| dp 含义 | s[i..j] **是否**回文 | s[i..j] 最长回文子序列**长度** |
| 相同时 | 首尾相同 + 内部是回文 → true | `dp[i+1][j-1] + 2` |
| 不同时 | false | `max(dp[i+1][j], dp[i][j-1])` |
| 遍历方向 | i 从下到上，j 从左到右 | 同左 |

## 十、避坑指南

### 🔴 背包遍历顺序

| 背包类型 | 内层遍历 | 原因 |
|---------|---------|------|
| 0-1 背包 | **倒序** | 防止同一物品被重复选取 |
| 完全背包 | **正序** | 允许同一物品重复选取 |

### 🔴 组合 vs 排列

| 类型 | 外层 | 内层 | 典型题 |
|------|------|------|--------|
| 组合数 | 物品 | 容量 | 518.零钱兑换II |
| 排列数 | 容量 | 物品 | 377.组合总和IV |

搞反了就会把排列当组合（或反过来），结果必然错误。

### 🔴 dp 初始化的坑

- **求最大值**：初始化为 0（或负无穷），不要用正无穷
- **求最小值**：初始化为 INF（如 `amount+1`），不要用 0
- **求方案数**：`dp[0] = 1`（空集算一种方案），不要用 0

### 🔴 dp 答案的位置

- 一维 dp：通常是 `dp[n]` 或 `dp[target]`
- 二维 dp（子序列类）：通常是 `dp[len1][len2]`
- **例外**：LIS 答案是 `max(dp[])`，不是 `dp[n-1]`；回文子串答案是遍历过程中累加

### 🔴 股票系列的初始化

- 第一次买入：`dp[0][买入状态] = -prices[0]`
- 卖出状态：`dp[0][卖出状态] = 0`
- 第二次买入也要初始化为 `-prices[0]`（逻辑上相当于当天买+卖+再买）

### 🔴 回文 DP 的遍历方向

`dp[i][j]` 依赖 `dp[i+1][j-1]`，所以 **i 必须从大往小**遍历（从下到上），j 从小到大。

### 🔴 494.目标和 的坑

- `left = (target + sum) / 2`，如果 `target + sum` 为奇数，直接返回 0
- `target` 可能超出 `[-sum, sum]` 范围，也要判掉
- dp[0] 初始化为 1 不是 0
