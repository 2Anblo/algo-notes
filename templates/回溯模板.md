# 回溯算法模板总结

> 基于代码随想录回溯专题提炼，涵盖组合、切割、子集、排列、去重、棋盘六大类。

---

## 1. 回溯核心思想

回溯 = **树形 DFS** + **撤销选择**。

- 把所有选择画成一棵决策树，**横向遍历**是 for 循环（本层选择），**纵向遍历**是递归（下一层选择）。
- 每到叶子节点收集一条路径，回溯时**撤销**上一步选择，换下一个分支继续搜索。
- 本质是**暴力枚举**，但通过剪枝可以大幅减少搜索量。

```
         根(空路径)
        / | \
       1  2   3       ← 横向：for 循环枚举选择
      /|  |\   \
     2 3  3 …  …      ← 纵向：递归进入下一层
    ↓ ↓
  收集路径 → 回溯 → 换分支
```

## 2. 通用回溯模板

```java
List<List<...>> result = new ArrayList<>();  // 结果集
List<...> path = new LinkedList<>();          // 当前路径

void backtrack(参数) {
    if (终止条件) {
        result.add(new ArrayList<>(path));  // 收集（注意深拷贝！）
        return;
    }
    for (选择 : 本层选择列表) {
        做选择;        // path.add(...)
        backtrack(下一层参数);
        撤销选择;      // path.removeLast()
    }
}
```

**关键三步**：做选择 → 递归 → 撤销选择，对应树的"进入子节点 → 深入 → 回到父节点"。

## 3. 组合问题

> **特点**：不强调元素顺序，用 `startIndex` 控制搜索起点，避免重复组合。

### 通用代码框架

```java
void backtrack(int[] nums, int k, int startIndex) {
    if (path.size() == k) {           // 终止：选够 k 个
        result.add(new ArrayList<>(path));
        return;
    }
    for (int i = startIndex; i <= nums.length - (k - path.size() - 1); i++) {
        //                       ↑ 剪枝：剩余元素不够就提前终止
        path.add(nums[i]);
        backtrack(nums, k, i + 1);    // i+1：不回头选
        path.removeLast();
    }
}
```

**剪枝公式**：`i <= n - (k - path.size() - 1)`，剩余可选元素不足时提前退出。

### 适用题目

| 题号 | 题目 | 关键点 |
|------|------|--------|
| 77 | 组合 | 基础模板，`startIndex` + 剪枝 |
| 216 | 组合总和 III | 加 `sum` 变量，`sum > n` 提前返回 |
| 17 | 电话号码的字母组合 | 每层对应一个数字，选择列表是字母映射 |
| 39 | 组合总和 | **元素可重复选**，递归传 `i`（不是 `i+1`） |
| 40 | 组合总和 II | 元素不可重复选 + 树层去重（见第 7 节） |

## 4. 切割问题

> **特点**：在字符串上切分，本质也是组合——用 `startIndex` 表示切割起点，`i` 表示切割终点。

### 通用代码框架

```java
void backtrack(String s, int startIndex) {
    if (startIndex == s.length()) {   // 终止：切到末尾
        result.add(new ArrayList<>(path));
        return;
    }
    for (int i = startIndex; i < s.length(); i++) {
        if (isValid(s, startIndex, i)) {  // 判断切割子串是否合法
            path.add(s.substring(startIndex, i + 1));
            backtrack(s, i + 1);          // 下一层从 i+1 开始切
            path.removeLast();
        }
    }
}
```

**核心**：`s[startIndex..i]` 就是一个切割段，合法性判断视题目而定（回文串、IP段等）。

### 适用题目

| 题号 | 题目 | 关键点 |
|------|------|--------|
| 131 | 分割回文串 | `isValid` = 双指针判回文 |
| 93 | 复原 IP 地址 | `isValid` = 判断 0-255 + 无前导零，需额外维护 `count` 记录点数 |

## 5. 子集问题

> **特点**：收集**所有节点**（不只是叶子），每进入一个节点就 `result.add`。

### 通用代码框架

```java
void backtrack(int[] nums, int startIndex) {
    result.add(new ArrayList<>(path));   // 收集每个节点！
    for (int i = startIndex; i < nums.length; i++) {
        // 可选：树层去重（见第7节）
        path.add(nums[i]);
        backtrack(nums, i + 1);
        path.removeLast();
    }
}
```

**与组合的区别**：组合只在叶子收集，子集在每个节点都收集。

### 适用题目

| 题号 | 题目 | 关键点 |
|------|------|--------|
| 78 | 子集 | 基础模板，无重复元素 |
| 90 | 子集 II | 有重复元素，排序 + 树层去重 |
| 491 | 递增子序列 | **不能排序**，用 `HashSet` 本层去重 + 递增剪枝 |

## 6. 排列问题

> **特点**：强调顺序，不用 `startIndex`，每层从 `0` 开始遍历，用 `used[]` 数组标记已选元素。

### 通用代码框架

```java
void backtrack(int[] nums, int[] used) {
    if (path.size() == nums.length) {   // 终止：排满
        result.add(new ArrayList<>(path));
        return;
    }
    for (int i = 0; i < nums.length; i++) {  // 从 0 开始！
        if (used[i] == 1) continue;           // 跳过已用元素
        // 可选：树层去重（见第7节）
        path.add(nums[i]);
        used[i] = 1;
        backtrack(nums, used);
        used[i] = 0;
        path.remove(path.size() - 1);
    }
}
```

**与组合的区别**：组合用 `startIndex`（不回头），排列用 `used[]`（可回头但不用同一元素）。

### 适用题目

| 题号 | 题目 | 关键点 |
|------|------|--------|
| 46 | 全排列 | 基础模板，`used[]` 标记 |
| 47 | 全排列 II | 有重复元素，排序 + 树层去重 |

## 7. 去重策略

> **核心问题**：数组含重复元素时，如何避免结果重复？

### 前提：排序

```java
Arrays.sort(nums);  // 排序使相同元素相邻
```

### 方法一：`used[]` 数组（可排序时）

```java
// 树层去重（最常用）
if (i > 0 && nums[i] == nums[i - 1] && used[i - 1] == 0) continue;
```

| 条件 | 含义 |
|------|------|
| `nums[i] == nums[i-1]` | 当前元素与前一个相同 |
| `used[i-1] == 0` | 前一个元素已回溯（同层）→ **跳过** |
| `used[i-1] == 1` | 前一个元素在路径中（同枝）→ **保留** |

**记忆**：`used[i-1] == 0` 是树层去重，`used[i-1] == 1` 是树枝去重（一般不剪）。

### 方法二：`HashSet` 本层去重（不可排序时）

```java
Set<Integer> used = new HashSet<>();  // 声明在递归函数内部！
for (int i = startIndex; i < nums.length; i++) {
    if (used.contains(nums[i])) continue;
    used.add(nums[i]);
    // 正常做选择 / 递归 / 撤销
}
```

适用场景：题目要求不能改变原数组顺序（如 491.递增子序列）。

### 去重对照表

| 题号 | 去重方式 | 原因 |
|------|----------|------|
| 40 | 排序 + `used[]` | 可排序，组合问题 |
| 90 | 排序 + `used[]` | 可排序，子集问题 |
| 47 | 排序 + `used[]` | 可排序，排列问题 |
| 491 | `HashSet` 本层 | 不能排序（需保持原序递增） |

## 8. 棋盘问题

> **特点**：二维棋盘，每行/每列/对角线有约束，逐行放置。

### N 皇后

```java
void backtrack(int n, int row, char[][] board) {
    if (row == n) {                      // 终止：放满 n 行
        result.add(constructBoard(board));
        return;
    }
    for (int col = 0; col < n; col++) {
        if (isValid(n, row, col, board)) {  // 检查列 + 两条对角线
            board[row][col] = 'Q';
            backtrack(n, row + 1, board);    // 下一行
            board[row][col] = '.';           // 撤销
        }
    }
}

boolean isValid(int n, int row, int col, char[][] board) {
    // 检查同列
    for (int i = 0; i < row; i++)
        if (board[i][col] == 'Q') return false;
    // 检查左上对角线 (\)
    for (int i = row - 1, j = col - 1; i >= 0 && j >= 0; i--, j--)
        if (board[i][j] == 'Q') return false;
    // 检查右上对角线 (/)
    for (int i = row - 1, j = col + 1; i >= 0 && j < n; i--, j++)
        if (board[i][j] == 'Q') return false;
    return true;
}
```

### 解数独

```java
boolean backtrack(char[][] board) {
    for (int i = 0; i < 9; i++) {
        for (int j = 0; j < 9; j++) {
            if (board[i][j] != '.') continue;
            for (char k = '1'; k <= '9'; k++) {
                if (isValid(i, j, k, board)) {
                    board[i][j] = k;
                    if (backtrack(board)) return true;  // 找到唯一解直接返回
                    board[i][j] = '.';
                }
            }
            return false;  // 1-9 都不行，当前路径无解
        }
    }
    return true;  // 没有空格了，解成功
}
```

**与 N 皇后的区别**：数独只需一个解，用 `boolean` 返回值提前终止。

### 适用题目

| 题号 | 题目 | 关键点 |
|------|------|--------|
| 51 | N 皇后 | 收集所有方案，逐行放 + 列/对角线检查 |
| 52 | N 皇后 II | 只计数，不需要存方案 |
| 37 | 解数独 | `boolean` 返回值，找到唯一解即停 |

## 9. 避坑指南

| 坑 | 说明 | 解法 |
|----|------|------|
| 🔴 忘记深拷贝 | `result.add(path)` 后 path 继续变，结果全错 | `result.add(new ArrayList<>(path))` |
| 🔴 撤销不完整 | 做了 `path.add` 和 `sum +=`，只撤销了一个 | 每个做选择操作都必须对应撤销 |
| 🔴 startIndex 传错 | 组合传 `i`（可重复）还是 `i+1`（不可重复）搞混 | 元素可重复选 → 传 `i`；不可重复 → 传 `i+1` |
| 🟡 排列用了 startIndex | 排列每层从 0 开始，不是 startIndex | 排列用 `used[]`，不用 `startIndex` |
| 🟡 去重前没排序 | `nums[i] == nums[i-1]` 依赖相邻相同元素 | **必须先 `Arrays.sort`** |
| 🟡 used 位置搞错 | 递归函数外声明 vs 函数内声明 | `used[]` 全局 → 树层+树枝去重；`HashSet` 局部 → 仅本层去重 |
| 🟢 子集忘收集根节点 | 空集 `[]` 也是子集 | 在 for 循环**之前**就 `result.add` |
| 🟢 数独只返回 void | 题目保证唯一解，找到就停 | 用 `boolean` 返回值提前终止 |
