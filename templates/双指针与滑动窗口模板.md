# 双指针与滑动窗口模板总结

> 从 30+ 道 LeetCode 实战中提炼的双指针与滑动窗口万能框架。掌握 **4 个模板**，覆盖所有变体。

---

## 一、核心思想

双指针和滑动窗口的本质都是**用两个指针维护一个区间，避免暴力枚举所有子区间**。

区别在于：

| 技法 | 指针运动方向 | 适用场景 |
|------|------------|---------|
| **对撞指针** | 左→ ←右，相向而行 | 有序数组上的配对/查找 |
| **快慢指针** | 同向而行，一快一慢 | 原地修改/链表/判环 |
| **定长滑窗** | 同向，窗口大小固定 | 固定长度的子数组/子串 |
| **不定长滑窗** | 同向，窗口大小可变 | 满足某条件的最长/最短/计数 |

---

## 二、对撞指针模板

**特征**：数组有序（或可排序），左右两端向中间靠拢。

### 模板1：反转/交换

```java
int left = 0, right = n - 1;
while (left < right) {
    swap(arr, left, right);  // 或其他操作
    left++;
    right--;
}
```

**适用题目**：
- [344. 反转字符串](https://leetcode.cn/problems/reverse-string/) — 左右交换
- [151. 反转字符串中的单词](https://leetcode.cn/problems/reverse-words-in-a-string/) — 整体反转 + 逐词反转

> **151 题三步法**：①快慢指针去多余空格 → ②整体反转 → ③逐词反转。这是字符串反转类题的经典套路。

### 模板2：N数之和

```java
// 以三数之和为例，四数之和多套一层循环
Arrays.sort(nums);
for (int i = 0; i < n - 2; i++) {
    if (i > 0 && nums[i] == nums[i - 1]) continue;  // 去重
    
    int left = i + 1, right = n - 1;
    while (left < right) {
        long sum = (long) nums[i] + nums[left] + nums[right];
        if (sum > target) {
            right--;
        } else if (sum < target) {
            left++;
        } else {
            result.add(Arrays.asList(nums[i], nums[left], nums[right]));
            // 去重：跳过相同的 left 和 right
            while (left < right && nums[left] == nums[left + 1]) left++;
            while (left < right && nums[right] == nums[right - 1]) right--;
            left++;
            right--;
        }
    }
}
```

**适用题目**：
- [15. 三数之和](https://leetcode.cn/problems/3sum/) — 固定1个 + 对撞双指针，O(n²)
- [18. 四数之和](https://leetcode.cn/problems/4sum/) — 固定2个 + 对撞双指针，O(n³)

**关键细节**：
- 先排序！排序后才能用对撞指针
- 去重分两层：外层循环去重（`i > 0 && nums[i] == nums[i-1]`）+ 内层双指针去重
- 四数之和注意 `long` 防溢出，剪枝时也要用 `long`

## 三、快慢指针模板

**特征**：同向而行，快指针探路，慢指针记录结果位置。

### 模板1：读写指针（原地修改）

```java
int write = 0;  // 慢指针：写位置
for (int read = 0; read < n; read++) {  // 快指针：读位置
    if (满足条件) {
        arr[write++] = arr[read];
    }
}
return write;  // write 即新长度
```

**适用题目**：
- [27. 移除元素](https://leetcode.cn/problems/remove-element/) — `val != nums[read]` 时写
- [54. 替换数字](https://leetcode.cn/problems/replace-number/) — 从右往左的双指针填充（字符串扩容）
- [151. 反转字符串中的单词](https://leetcode.cn/problems/reverse-words-in-a-string/) — 快慢指针去空格

> **54 题技巧**：字符串扩容题，先算新长度，再从后往前填充。因为从前往后会覆盖，从后往前不会。

### 模板2：链表双指针

```java
// 反转链表
ListNode prev = null, curr = head;
while (curr != null) {
    ListNode next = curr.next;
    curr.next = prev;
    prev = curr;
    curr = next;
}
return prev;
```

**适用题目**：
- [206. 反转链表](https://leetcode.cn/problems/reverse-linked-list/) — prev/curr 翻转

### 模板3：快慢指针找特殊位置

```java
// 删除倒数第N个：fast先走N+1步，然后同步走
ListNode dummy = new ListNode(0, head);
ListNode fast = dummy, slow = dummy;
for (int i = 0; i <= n; i++) fast = fast.next;
while (fast != null) {
    fast = fast.next;
    slow = slow.next;
}
slow.next = slow.next.next;
return dummy.next;
```

**适用题目**：
- [19. 删除链表的倒数第N个结点](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/) — fast先走N+1步
- [面试题02.07. 链表相交](https://leetcode.cn/problems/intersection-of-two-linked-lists/) — 双指针交叉走（A走完走B）
- [142. 环形链表II](https://leetcode.cn/problems/linked-list-cycle-ii/) — 快慢判环 + 入口定位

> **链表相交**：pA走A再走B，pB走B再走A，相遇点即交点（或null）。
>
> **环形链表II**：快指针2步/慢指针1步，相遇后一个从head出发，一个从相遇点出发，再次相遇即入口。数学推导：`x = (n-1)(y+z) + z`。

## 四、定长滑动窗口模板（三步法）

**特征**：窗口大小固定为 k，每次右移一步，维护窗口内统计量。

### 万能三步法

```
每轮循环中：
1. 入 — 右端点 i 进入窗口，更新统计量
2. 更新 — 窗口已形成（i >= k-1）时，用统计量更新答案
3. 出 — 左端点 i-k+1 离开窗口，更新统计量
```

### Java 模板

```java
// 预处理：前 k-1 个元素先入窗
for (int i = 0; i < k - 1; i++) {
    // 统计量 += arr[i]
}

// 主循环：从第 k 个元素开始
for (int i = k - 1; i < n; i++) {
    // ① 入：右端点 i 进入
    // 统计量 += arr[i]
    
    // ② 更新：用统计量更新答案
    // ans = Math.max/min(ans, 统计量)
    
    // ③ 出：左端点 i-k+1 离开
    // 统计量 -= arr[i - k + 1]
}
```

### 变体：需要 HashMap 维护种类数

```java
Map<Integer, Integer> map = new HashMap<>();
int type = 0;  // 不同元素种类数

// 入
int cnt = map.getOrDefault(arr[i], 0);
if (cnt == 0) type++;
map.put(arr[i], cnt + 1);

// 出
cnt = map.get(arr[i - k + 1]);
if (cnt == 1) type--;
map.put(arr[i - k + 1], cnt - 1);
```

## 五、不定长滑动窗口 - 求最长/最大

**特征**：窗口内满足某条件，求最大窗口长度。

### 模板

```java
int left = 0, ans = 0;
Map<Key, Integer> map = new HashMap<>();  // 或 int[] cnt

for (int right = 0; right < n; right++) {
    // 右端点进入窗口
    map.merge(arr[right], 1, Integer::sum);
    
    // 收缩：窗口不满足条件时，左边界右移
    while (不满足条件) {
        map.merge(arr[left++], -1, Integer::sum);
    }
    
    // 更新答案
    ans = Math.max(ans, right - left + 1);
}
```

**核心逻辑**：右端点扩展导致"破坏条件"，左端点收缩"恢复条件"。

### 常见条件判断

| 条件 | 判断方式 |
|------|---------|
| 无重复字符 | `cnt[s[right]] > 1` |
| 每个字符最多出现k次 | `cnt[s[right]] > k` |
| 最多K个重复元素 | `map.get(nums[right]) > k` |
| 最多2种水果 | `map.size() > 2` |
| 窗口和不超过budget | `sum > maxCost` |
| 0的个数不超过k | `zeroCnt > k` |

## 六、不定长滑动窗口 - 求最短/最小

**特征**：窗口内满足某条件，求最小窗口长度。与"求最长"相反——**条件满足时才收缩**。

### 模板

```java
int left = 0, ans = Integer.MAX_VALUE;
// 统计量

for (int right = 0; right < n; right++) {
    // 右端点进入窗口
    
    // 当窗口满足条件时，尝试收缩左边界（越短越好）
    while (满足条件) {
        ans = Math.min(ans, right - left + 1);
        // 移出左端点
        left++;
    }
}
```

**关键区别**：

| | 求最长 | 求最短 |
|--|--------|--------|
| 收缩时机 | 条件**不满足**时收缩 | 条件**满足**时收缩 |
| 更新时机 | 条件满足时更新 | 条件满足时更新（收缩前） |
| 收缩目的 | 恢复合法性 | 寻找更优解 |

**适用题目**：

| 题目 | 条件 | 难度 |
|------|------|------|
| [209. 长度最小的子数组](https://leetcode.cn/problems/minimum-size-subarray-sum/) | 和≥target | ⭐⭐ |
| [3795. 不同元素和至少为K的最短子数组](https://leetcode.cn/problems/minimum-subarray-length-with-distinct-sum-at-least-k/) | 不同元素和≥k | ⭐⭐⭐ |
| [76. 最小覆盖子串](https://leetcode.cn/problems/minimum-window-substring/) | 包含T所有字符 | ⭐⭐⭐ |
| [2904. 最短且字典序最小的美丽子字符串](https://leetcode.cn/problems/shortest-and-lexicographically-smallest-beautiful-string/) | 1的个数==k + 字典序最小 | ⭐⭐⭐ |

### 76. 最小覆盖子串 — 滑窗天花板

```java
// 用 missing 变量优化：还缺多少字符
int[] need = new int[128];
int missing = t.length;  // 还缺的字符总数

for (char ch : t.toCharArray()) need[ch]++;

int left = 0;
for (int right = 0; right < s.length; right++) {
    if (need[s[right]] > 0) missing--;  // 有用的字符，缺数-1
    need[s[right]]--;                    // 允许负数（多余的字符）
    
    while (missing == 0) {  // 窗口已覆盖 T
        // 更新答案...
        
        need[s[left]]++;
        if (need[s[left]] > 0) missing++;  // 移出关键字符
        left++;
    }
}
```

> **missing 技巧**：用 `need[]` 数组允许负数（表示多余），`missing` 只在关键字符进出时变化，O(1) 判断覆盖。

## 七、不定长滑动窗口 - 求子数组个数（★核心难点）

这是滑动窗口最复杂的变体，关键在于**增量计数**。

### 核心公式

有两种计数方式，取决于"合法子数组的定义"：

```
方式A：窗口内满足条件 → ans += right - left + 1
方式B：窗口外满足条件 → ans += left
```

### 方式A：窗口内满足条件

**含义**：当前窗口 `[left, right]` 满足条件，则以 `right` 结尾的合法子数组有 `right - left + 1` 个。

```
窗口 [2, 3, 1] 满足条件（无重复）
以 right=4 结尾的合法子数组：[1], [3,1], [2,3,1] → 3个 = 窗口长度
```

```java
int left = 0, ans = 0;
for (int right = 0; right < n; right++) {
    // 右端点进入
    // ...
    
    // 收缩到窗口合法
    while (窗口不合法) {
        // 移出左端点
        left++;
    }
    
    // 窗口合法，增量计数
    ans += right - left + 1;
}
```

| 题目 | 条件 | 难度 |
|------|------|------|
| [713. 乘积小于K的子数组](https://leetcode.cn/problems/subarray-product-less-than-k/) | 乘积<k | ⭐⭐ |
| [2743. 没有重复字符的子字符串数量](https://leetcode.cn/problems/count-substrings-without-repeating-character/) | 无重复 | ⭐⭐ |
| [3258. K约束子字符串数量](https://leetcode.cn/problems/count-substrings-that-satisfy-k-constraint-i/) | 0≤k 或 1≤k | ⭐⭐ |
| [LCP68. 美观的花束](https://leetcode.cn/problems/1GxJYY/) | 每种≤cnt | ⭐⭐ |

> **713 乘积<k**：增量计数的经典题。窗口内乘积<k，则窗口内每个以right结尾的子数组都合法。

### 方式B：窗口外满足条件（"至少包含"类）

**含义**：窗口收缩到**刚好不满足条件**，此时 `left` 表示最左边的合法起点位置，所以 `[0, left-1]` 这些起点都能形成合法子数组，共 `left` 个。

```
条件：至少包含一个1
数组：[0, 1, 0]
right=2 时，窗口收缩到 left=1（刚好不满足）
起点可以是 0 或 1，共 left=2 个合法子数组：[0,1,0], [1,0]
```

```java
int left = 0, ans = 0;
for (int right = 0; right < n; right++) {
    // 右端点进入
    // ...
    
    // 收缩到窗口刚好不满足条件
    while (窗口满足条件) {
        // 移出左端点
        left++;
    }
    
    // left 之前的起点都合法
    ans += left;
}
```

### 方式C：容斥原理 — 恰好等于K

```
恰好 k 个 = 至少 k 个 - 至少 (k+1) 个
```

```java
int exactlyK(int[] nums, int k) {
    return atMostK(nums, k) - atMostK(nums, k - 1);
    // 或: return atLeastK(nums, k) - atLeastK(nums, k + 1);
}
```

**适用题目**：

| 题目 | 恰好条件 | 转化方式 |
|------|---------|---------|
| [930. 和相同的二元子数组](https://leetcode.cn/problems/binary-subarrays-with-sum/) | 和==goal | <goal+1 的个数 - <goal 的个数 |
| [1248. 优美子数组](https://leetcode.cn/problems/count-number-of-nice-subarrays/) | 恰好k个奇数 | ≥k的个数 - ≥(k+1)的个数 |

### 方式A vs 方式B 速查表

| 问题问法 | 计数方式 | 窗口状态 |
|---------|---------|---------|
| "乘积/和 **小于** K" | `ans += right - left + 1` | 窗口内满足 |
| "无重复字符的子串数" | `ans += right - left + 1` | 窗口内满足 |
| "**至少包含** 某条件" | `ans += left` | 窗口外满足 |
| "恰好等于 K" | 容斥：≥K - ≥(K+1) | 两次窗口 |

## 八、避坑指南

| 坑 | 正确做法 |
|----|---------|
| 求最长时死循环 | 收缩条件是不满足条件时才缩，不是满足时缩 |
| 求最短时更新遗漏 | 在收缩**之前**更新答案，收缩之后窗口可能不满足了 |
| 子数组计数搞混A/B | 记住：窗口内合法用 `right-left+1`，窗口外合法用 `left` |
| 恰好K想不到容斥 | `恰好K = 至少K - 至少(K+1)`，这是通用套路 |
| HashMap 种类数维护错 | 入时 `cnt==0` 才 type++，出时 `cnt==1` 才 type-- |
| 乘积溢出 | 用 `long` 或提前判 `k<=1` 直接返回0 |
| 四数之和整数溢出 | `sum` 用 `long`，剪枝 `min/max` 也用 `long` |
| 链表删除忘记 dummy | 删除头结点时需要虚拟头结点保护 |
| 滑窗预处理遗漏 | 定长滑窗先处理前 k-1 个，不定长不用 |
| 窗口收缩后忘记更新统计量 | 出窗口时必须同步减少计数/和/种类数 |
