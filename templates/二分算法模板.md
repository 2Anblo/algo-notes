# 二分算法模板总结

> 从 LeetCode 实战中提炼的二分算法万能模板。你只需要掌握 **一个核心函数**，就能秒杀所有二分题。

---

## 一、核心思想

二分的本质不是"在有序数组里找一个数"，而是**在单调的判定函数上找分界点**。

无论题目怎么变，最终都可以归约为：

> 找到**第一个满足条件**的位置（lower_bound）

---

## 二、万能模板：lower_bound

```java
/**
 * 返回第一个 >= target 的位置
 * 如果所有元素都 < target，返回 nums.length
 */
public int lowerbound(int[] nums, int target) {
    int left = 0;
    int right = nums.length - 1;

    while (right >= left) {
        int mid = left + (right - left) / 2;

        if (nums[mid] >= target) {
            right = mid - 1;  // mid 可能是答案，往左收缩
        } else {
            left = mid + 1;   // 答案在右边
        }
    }

    return left;  // left = 第一个 >= target 的位置
}
```

### 模板要点

| 要点 | 说明 |
|------|------|
| `right >= left` | 闭区间写法，退出时 `left = right + 1` |
| `mid = left + (right - left) / 2` | 防溢出，取偏左中点 |
| `nums[mid] >= target` | **关键！** 等号归到左边，保证收缩到左边界 |
| 返回 `left` | 即第一个 `>= target` 的位置 |

### 三个关键不变量

1. **答案永远在 `[left, right+1]` 中**
2. **`left` 左边的元素都 `< target`**
3. **`right` 右边的元素都 `>= target`**

---

## 三、从 lower_bound 衍生出的所有变体

掌握了 `lower_bound`，所有变体都是一行转换：

| 需求 | 转换方式 | 示例 |
|------|---------|------|
| **第一个 >= target** | 直接调 `lowerbound(nums, target)` | 搜索插入位置 |
| **第一个 > target** | `lowerbound(nums, target + 1)` | 寻找比目标大的最小字母 |
| **最后一个 == target** | `lowerbound(nums, target + 1) - 1` | 查找区间的右边界 |
| **最后一个 <= target** | `lowerbound(nums, target + 1) - 1` | 时间键值存储 |
| **严格大于的个数** | `n - lowerbound(nums, target + 1)` | 比较字符串频次 |
| **>= target 的个数** | `n - lowerbound(nums, target)` | 咒语和药水 |

### 口诀

> **找左用 lower_bound，找右用 lower_bound - 1，找 > 等价于找 >= (target+1)**

## 四、题型分类与实战

### 类型一：精确查找 / 左右边界

**特征**：有序数组中找 target 的位置或边界

#### [34. 在排序数组中查找元素的第一个和最后一个位置](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/)

```java
public int[] searchRange(int[] nums, int target) {
    int start = lowerbound(nums, target);  // 左边界 = 第一个 >= target
    if (start == nums.length || nums[start] != target) {
        return new int[]{-1, -1};
    }
    // 右边界 = 第一个 >= target+1 的位置 - 1
    return new int[]{start, lowerbound(nums, target + 1) - 1};
}
```

**同类题目**：
- [704. 二分查找](https://leetcode.cn/problems/binary-search/) — 精确查找，`lowerbound` 后验证
- [35. 搜索插入位置](https://leetcode.cn/problems/search-insert-position/) — 直接返回 `lowerbound`

---

### 类型二：第一个大于 / 严格大于

**特征**：找第一个严格大于 target 的元素

#### [744. 寻找比目标字母大的最小字母](https://leetcode.cn/problems/find-smallest-letter-greater-than-target/)

```java
// "严格大于 target" 等价于 ">= (target + 1)"
int start = lowerbound(letters, (char)(target + 1));
return start == letters.length ? letters[0] : letters[start];
```

---

### 类型三：区间计数 / 范围统计

**特征**：统计满足某条件的元素个数，本质是找分界点

#### [2529. 正整数和负整数的最大计数](https://leetcode.cn/problems/maximum-count-of-positive-integer-and-negative-integer/)

```java
// 负数个数 = 第一个 >= 0 的位置
int neg = lowerbound(nums, 0);
// 正数个数 = 总数 - 第一个 >= 1 的位置
int pos = nums.length - lowerbound(nums, 1);
return Math.max(pos, neg);
```

#### [1385. 两个数组间的距离值](https://leetcode.cn/problems/find-the-distance-value-between-two-arrays/)

```java
// 对每个 arr1[i]，检查 arr2 中是否有元素落在 [arr1[i]-d, arr1[i]+d]
// 等价于：第一个 >= arr1[i]-d 的元素是否 <= arr1[i]+d
int left = lowerbound(arr2, n - d);
if (left == arr2.length || arr2[left] > n + d) {
    ans++;  // 不存在落在区间内的元素
}
```

#### [2300. 咒语和药水的成功对数](https://leetcode.cn/problems/successful-pairs-of-spells-and-potions/)

```java
// spell * potion >= success => potion >= ceil(success / spell)
long target = success % num == 0 ? success / num : success / num + 1;
int idx = lowerbound(potions, target);
spells[i] = potions.length - idx;  // 右侧都满足
```

#### [1170. 比较字符串最小字母出现频次](https://leetcode.cn/problems/compare-strings-by-frequency-of-smallest-character/)

```java
// 找 words 中 f(w) > f(query) 的个数
// 等价于 n - lowerbound(sortedFreq, f(query) + 1)
int low = lowerbound(arr2, arr1[i] + 1);
arr1[i] = arr2.length - low;
```

---

### 类型四：前缀和 + 二分

**特征**：排序后转前缀和，再用二分找边界

#### [2389. 和有限的最长子序列](https://leetcode.cn/problems/longest-subsequence-with-limited-sum/)

```java
Arrays.sort(nums);
prefixSum(nums);  // 原地转前缀和
// 找第一个 > queries[i] 的位置，即前缀和 <= queries[i] 的最大长度
queries[i] = lowerbound(nums, queries[i] + 1);
```

**技巧**：排序 + 前缀和之后，前缀和数组天然单调，可以用二分。

---

### 类型五：二分查找右边界（最后一个 <= target）

**特征**：找最后一个满足条件的位置，不等式方向翻转

#### [981. 基于时间的键值存储](https://leetcode.cn/problems/time-based-key-value-store/)

```java
// 找最后一个 timestamp <= target 的 Pair
// 不变量：left 左边都 <= target，right 右边都 > target
while (left <= right) {
    int mid = left + (right - left) / 2;
    if (list.get(mid).timestamp > timestamp) {
        right = mid - 1;
    } else {
        left = mid + 1;  // <= 的情况，可能是答案，继续往右
    }
}
// left - 1 是最后一个 <= timestamp 的位置
return left > 0 ? list.get(left - 1).value : "";
```

> **对比**：左边界找法是 `>= target` 往左收缩；右边界找法是 `<= target` 往右扩张。两者对称。

---

### 类型六：二分 + 最近点查询

**特征**：在有序位置数组中，找到离目标最近的点

#### [1182. 与目标颜色间的最短距离](https://leetcode.cn/problems/shortest-distance-to-target-color/)

```java
// 找第一个 >= idx 的位置 left
// 候选答案只有两个：left 或 left-1
// 取距离更近的那个
if (left == list.size()) {
    // 所有位置都在 idx 左边
    ans = idx - list.get(left - 1);
} else if (left > 0) {
    // 左右都可能，取 min
    ans = Math.min(idx - list.get(left - 1), list.get(left) - idx);
} else {
    // 所有位置都在 idx 右边
    ans = list.get(left) - idx;
}
```

> **技巧**：有序数组中找离 target 最近的元素，先 `lowerbound` 找分界点，再比较左右邻居。

## 五、二分答案（值域二分）

上面所有题型都是在**有序数组**上二分，但还有一类题是在**值域**上二分：

> 答案具有单调性：如果 x 满足条件，那么 > x（或 < x）也满足

这类题的模板：

```java
// 最小化最大值 / 最大化最小值 / 第 K 小
int left = minPossible, right = maxPossible;

while (left <= right) {
    int mid = left + (right - left) / 2;

    if (check(mid)) {
        // mid 满足条件，尝试更优解
        right = mid - 1;  // 或 left = mid + 1
    } else {
        left = mid + 1;   // 或 right = mid - 1
    }
}

// left 即为答案
```

**关键**：`check(mid)` 函数是每道题的核心，需要自己设计。

---

## 六、避坑指南

| 坑 | 正确做法 |
|----|---------|
| `mid = (left + right) / 2` 溢出 | `mid = left + (right - left) / 2` |
| 开闭区间混乱 | 统一用闭区间 `[left, right]`，退出条件 `left > right` |
| 找右边界时死循环 | 右边界 = `lowerbound(target+1) - 1`，别另起炉灶 |
| 忘记检查越界 | `lowerbound` 可能返回 `nums.length`，一定要判 |
| 整数除法向上取整 | `(a + b - 1) / b` 或 `a % b == 0 ? a/b : a/b + 1` |
| 二分答案忘了 check | 值域二分的核心是 `check` 函数，不是二分本身 |
